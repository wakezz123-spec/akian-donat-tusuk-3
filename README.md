# Donat Tusuk Akian

Website landing page responsif untuk Donat Tusuk Akian. Dibuat dengan HTML, CSS, dan JavaScript biasa, sehingga mudah diunggah ke GitHub dan Vercel.

## Sebelum dipublikasikan
1. Buka `script.js`, lalu ganti `6281234567890` dengan nomor WhatsApp bisnis.
2. Di `index.html`, ubah nama varian dan deskripsi menu contoh sesuai produk asli.
3. Tambahkan harga, alamat, jam buka, foto produk, dan akun media sosial jika sudah tersedia.

## Upload ke GitHub
1. Buat repository baru di GitHub, misalnya `donat-tusuk-akian`.
2. Upload semua file dalam folder ini (`index.html`, `style.css`, `script.js`, `favicon.svg`, dan `README.md`) ke root repository.
3. Pastikan `index.html` berada langsung di root, bukan di dalam folder tambahan.

## Deploy ke Vercel
1. Masuk ke https://vercel.com dan pilih **Continue with GitHub**.
2. Klik **Add New → Project**.
3. Import repository `donat-tusuk-akian`.
4. Framework Preset pilih **Other**. Build Command dan Output Directory bisa dikosongkan untuk website statis ini.
5. Klik **Deploy**. Vercel akan memberikan alamat website.
6. Setiap perubahan yang di-push ke branch utama GitHub akan otomatis di-deploy ulang oleh Vercel.

Tidak perlu menjalankan perintah build atau memasang package tambahan.
